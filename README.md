# Toolbox

Toolbox is a Docker-based development environment with selected tool versions pinned and a host-integrated shell. This repository defines its Debian image, runtime wrapper, and build and release automation.

- [Usage](docs/playbooks/usage.md): set up and use Toolbox.
- [Image maintenance](docs/playbooks/image-maintenance.md): build, check, and update the image.
- [Project overview](docs/overview.md): scope, source map, and documentation by topic.
